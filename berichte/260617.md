Es gibt aber viele verschiedene Sonderzeichen wie äöü dafür gab es keinen Platz deswegen wurden die Pages entwickelt die je nach Regeion anders waren.

## 1. XXD

Der Befehl `xxd` sorgt dafür das eingegebene Normale Buchstaben in Asc Code angezeigt werden.

bsp:
```sh
echo "a" | xxd
00000000: 610a                                     a.
```

### Die Optionen `-n -r -p` 

-n sorgt dafür das echo keinen Zeilenumbruch mehr dranhängt.

-p sorgt dafür das xxd nur mehr der Ascii Code angezeigt wird und nicht mehr die Stelle wo es liegt in Hex und was es in Normalen Zeichen ist.

-r sorgt dafür das xxd rückwärts funktionert also aus Ascci normale Zeichen macht.


bsp mit Emojis:

```sh
echo -n "😃" | xxd -p
f09f9883
```


```sh
echo -n "f09f9883" | xxd -r -p
😃
```

Um einen dezimalen Wert (ASCII Ziffern) als Binärwert in ein File zu schreiben können folgende Befehle verwendet werden:
$ value=65534
```  
$ printf "%.8x" $value | xxd -r -p >data.bin
```
Aufgabe:Was macht das printf und der Ausdruck %.8x?

Wie würdest du jemanden (mit einem Bash Grundverständnis) erklären wie diese Zeile die Aufgabenstellung löst.

Finde einen Weg um den 4 Byte Binärwert aus der Datei wieder als Dezimalwert darzustellen. 

Lösung:
$ printf "%.8x" $value gibt den Wert Value in Hexadezimal aus da %.8x sagt das mindestens 8 Stellen in hexadezimal ausgegeben werden müssen.

Die Zeile wandelt den wert im Value zuerst in Hexadezimal um, danach wird diese wieder in Binär umgewandelt und in die Datei geschrieben

Mit der Zeile:

```sh
echo $((16#$(xxd -p data.bin)))

65534
```

ist es möglkich es wieder in dezimal Zahlen auszugeben.

Aufgabe: Forschung/Recherche: Was ist der Unterschied zwischen ANSI und Latin-1?

Lösung:
Ansi ist oft ein Synonym für Windows-1252, also eine Erweiterung von Latin-1 für Windows. Der einzige große Unterschied ist das ein par Sonderzeichen mehr eingefügt wurden,
wie z.B. das Euro-Zeichen(€), die Anführungszeichen("") oder der Bindestrich(-). 
Latin-1 ist ein ISO-Standart (ISO 8859-1) der für Mitteleuropäische Sprachen gebraucht wird, dort waren diese Zeichen nicht enthalten.
